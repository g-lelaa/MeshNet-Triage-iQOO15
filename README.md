# MeshNet-Triage-iQOO15
The provided documents outline a pitch for MeshNet Triage, a decentralized disaster management system designed specifically for the iQOO 15 smartphone. When natural disasters inevitably destroy traditional cellular networks, this application leverages Android Wi-Fi Aware to establish an independent, self-healing mesh network of connected devices. By running an 8B quantized large language model locally, the system provides instant survival guidance and tracks emergency SOS signals without requiring internet access. To ensure reliable performance during critical situations, the platform utilizes the Snapdragon 8 Elite Gen 5's Hexagon NPU for efficient processing and exploits a massive 7,000 mAh battery for extended operational endurance. Finally, the project is spearheaded by a capable team combining advanced systems architecture expertise with rapid, agile user interface development to achieve an optimal balance of technical depth and fast execution.
