# MeshNet-Triage-iQOO15
We are building a decentralized crisis management hub for disaster victims and first responders when cellular networks fail. Using Android Wi-Fi Aware to form a local mesh network, the system routes SOS pings and triage queries to a quantized 8B LLM running entirely on the iQOO 15's Hexagon NPU, providing zero-latency offline survival guidance.
